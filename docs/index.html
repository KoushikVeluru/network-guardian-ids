Overview

Problem. Security teams receive huge volumes of network traffic. Traditional rule-based tools miss new attacks, and many ML detectors are black boxes, so analysts cannot see why a flow was flagged.

Our goal. Train accurate classifiers to separate BENIGN from ATTACK flows, then explain each decision with SHAP and turn it into a plain-English alert with recommended actions.

Approach

Network-flow dataset with features
Split into train / validation / test (seed 42)
Train Random Forest and XGBoost
Pick the champion on test metrics
Explain predictions with SHAP
Generate template-based alerts and risk score

Status & limitations

  • Done: data pipeline, two trained models, evaluation, SHAP explanations, template alerts, this results page.
  • Planned: live dashboard (React + FastAPI), check on completely unseen benign traffic.
  • Imbalanced test set: about of test flows are attacks, with only benign flows. The false positive rate is measured on a small benign sample.
  • Risk score barely varies: both attack examples scored 60.0 (HIGH) despite different SHAP evidence, so the formula separates confident attacks poorly.
  • Scaled vs raw values: waterfall plots show scaled features the model was trained on; alert text translates back to original units.
  • Alerts are templates: the detection is the ML model and the explanation is real SHAP, but no LLM writes the text.
